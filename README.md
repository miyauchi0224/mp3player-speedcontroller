# mp3player

**無料・広告なしの、シンプルな Android 向け MP3 プレーヤー**

端末に保存した MP3 を再生するアプリです。再生速度を 0.5〜4 倍で変えられるので、語学学習や講義、オーディオブックの聞き流しにも使えます。インターネットには接続せず、データはすべて端末内に保存します。

- 💰 無料・広告なし・アプリ内課金なし
- ⏩ 再生速度 0.5〜4 倍
- 🎧 アプリを閉じても再生を続けるバックグラウンド再生
- 🔒 インターネットに接続しない（[プライバシーポリシー](PRIVACY.md)）

> **English:** A free, ad-free MP3 player for Android with 0.5x–4x speed control and background playback. It never connects to the internet. See the [Privacy Policy](PRIVACY.md#english).

## 主な機能

### ⏩ スピードコントロール

- 再生速度を **0.5〜4 倍** で調整
- −／＋ボタンで 0.1 倍ずつ変更
- 候補（0.5x / 0.75x / 1.0x / 1.25x / 1.5x / 2.0x / 3.0x / 4.0x）からワンタップで選択

### ▶️ 再生

| 機能 | 内容 |
| --- | --- |
| まとめて再生 | 曲・アルバム・アーティスト・フォルダ単位 |
| シャッフル／リピート | シャッフル、1 曲リピート、アルバム・フォルダ全体のリピート |
| バックグラウンド再生 | 画面を消しても再生を継続。通知・ロック画面・Bluetooth／有線イヤホンのボタンで操作 |
| 音の調整 | 音量、イコライザー |
| 歌詞表示 | MP3 に埋め込まれた歌詞、または LRC ファイル。再生位置に合わせて強調表示 |
| スリープタイマー | 15 分／30 分／60 分後に自動で停止 |
| 再生状態の復元 | 前回の曲・再生位置・速度を次回起動時に復元 |

### 📚 ライブラリ

- 端末内の MP3 を自動で検索して一覧表示
- 対象にするフォルダの選択
- リスト表示とアイコン表示（ジャケットを大きく表示）の切り替え
- MP3 に埋め込まれたジャケット画像の表示
- 並べ替え・絞り込み（曲名・アーティスト・追加日など）
- タグ編集（曲名・アーティスト・アルバム）

### 📝 プレイリスト・履歴

- プレイリストの作成・編集・並べ替え
- M3U 形式でのエクスポート／インポート
- お気に入り
- 最近再生した曲、再生回数の多い曲

### 🧩 そのほか

- 音声録音
- クラウドからの読み込み（Google ドライブなど、端末に入っているクラウドアプリから選択）
- ホーム画面ウィジェット
- Android Auto
- ダークモード
- 日本語／英語表示

## プライバシー

- **インターネットに接続しません。** アプリにインターネット接続の権限がありません。
- **データを収集・送信しません。** 再生履歴・お気に入り・プレイリスト・設定は端末内にだけ保存します。
- **広告・解析ツールを使いません。**

詳しくは [プライバシーポリシー](PRIVACY.md) をご覧ください。

## 使用する権限

| 権限 | 使う場面 |
| --- | --- |
| 音楽ファイルへのアクセス | 端末内の MP3 を検索・再生する |

## 既知の制約

- **録音ファイルは MP3 ではなく AAC（.m4a）** で保存されます。Android の録音機能が MP3 での保存に対応していないためです。
- **タグ編集は Android のメディア情報だけを更新します。** MP3 ファイル内のタグ（ID3）自体は書き換えません。
- **歌詞ファイル（.lrc）は、Android 10 以降では設定の「歌詞フォルダ」で選んだフォルダから読み込みます。** MP3 に埋め込まれた歌詞は、フォルダを選ばなくても表示できます。
